# 우리 교실 디자인 다듬기 적용 지시서 (Claude Code용)

이 폴더는 Claude Design 캔버스에서 다듬은 디자인을 실제 앱(Electron)에 옮기기 위한 자료입니다.
**새로 디자인하는 것이 아니라, 지금 앱을 다듬는 작업입니다.** 기능은 그대로 두고 보이는 모습만 바꿉니다(아래 '명시한 변경'만 예외).

---

## 0. 먼저 읽기 · 작업 방법

### 0-1. 폴더 구성

| 경로 | 내용 |
|---|---|
| `tokens.css` | 색 · 글꼴 · 글자 크기 · 간격 · 모서리 · 그림자 · 터치 크기 변수(`--uc-*`) |
| `components.css` | 모든 화면이 함께 쓰는 공통 부품 클래스(`.uc-*`) |
| `icons/*.svg` | 선 아이콘 30개 + 날씨 아이콘(24×24, 선 굵기 2, 둥근 끝, `currentColor`) |
| `screens/*.png` | 다듬은 화면 56장. **각 단계에서 이 그림과 나란히 비교하며 맞춥니다.** |
| `우리교실_디자인적용_지시서.md` | 이 문서 |

`screens` 파일 이름 앞의 코드(A01, B02 …)는 이 문서의 단계 번호와 같습니다.
`00_` 세 장은 디자인 시스템(색·글씨·간격, 공통 부품)과 통일 확인표입니다.

### 0-2. 두 판(옥구초판 · 전국판)은 따로

- 저장소: `rlasksk030/class`
- **옥구초판(main)** 과 **전국판 브랜치**는 완전히 따로 개발·배포합니다. 서로 병합하지 않습니다.
- 두 판을 **서로 병합(merge)하지 않습니다.** 디자인 작업 브랜치 운영(예: 전국판 `feature/design-refresh-nationwide`에서 먼저 만들고 옥구초판 `feature/design-refresh-okgu`로 cherry-pick)은 사용자가 따로 준 **디자인 보완 지시서**의 방식을 따릅니다. cherry-pick 뒤에는 판 고유 부분(학교 고정, 서비스 고르기, 앱 ID, 업데이트 경로)이 섞이지 않았는지 꼭 확인합니다.
- 화면 중 판에 따라 다른 것: H01(옥구초판) / H02·H03(전국판), I01(옥구초판) / I02·I06(전국판). 나머지는 두 판이 같습니다.

### 0-3. 진행 규칙

1. **시작 전 백업**: 학생 명단·시간표·알림장·배치 등 앱에 저장된 데이터(로컬 저장소, `window.storage`, 설정 파일 등)를 먼저 백업하는 방법을 확인하고, 사용자에게 백업하라고 안내한 뒤 시작합니다. 저장 형식(키 이름, 파일 구조)은 바꾸지 않습니다. 새 설정값이 필요하면 **추가만** 하고 기본값을 둡니다.
2. 이 디자인 폴더는 저장소 안 `design/` 같은 곳에 두되, **설치 파일(빌드 결과)에는 넣지 않습니다.** 앱이 실제로 쓰는 `tokens.css`, `components.css`, 아이콘은 앱의 스타일·에셋 폴더로 복사해서 씁니다.
3. 아래 단계 순서대로, **단계마다 커밋**합니다. 커밋 메시지 예: `디자인 2단계: 대시보드 크기 규칙 적용`.
4. 단계가 끝날 때마다 앱을 실행해 **1440×900, 1100×760, 1920×1080** 세 크기에서 `screens` 그림과 비교하고, 다른 점을 사용자에게 짧게 알립니다.
5. 기존 코드에 있는 기능(버튼, 단축키, 저장, 자동 조회, 연동)은 지우지 않습니다. 모양만 바꾸다가 이벤트 연결이 끊기지 않았는지 단계마다 눌러 봅니다.

## 1. 공통 원칙

### 1-1. 지켜야 할 것

- **글꼴 두 가지만**
  - 고운바탕(Gowun Batang): 학생이 읽는 글. 제목, 시간표 과목, 급식, 시계, 아침활동·안내사항, 학생 이름, 큰 숫자.
  - 나눔바른고딕(NanumBarunGothic): 교사가 누르고 읽는 글. 버튼, 탭, 입력 칸, 안내 문구, 작은 표시.
  - 앱에 이미 들어 있는 글꼴 파일을 씁니다. **`tokens.css`의 `--uc-font-main`, `--uc-font-sub`에 적힌 이름을 앱의 `@font-face` 이름과 똑같이 맞춰 주세요.** 시스템 고딕(맑은 고딕 등)으로 떨어지는 곳이 없어야 합니다(특히 타이머 숫자).
- **외부 리소스 금지**: 글꼴·아이콘을 인터넷에서 불러오지 않습니다(교실 인터넷이 막힐 수 있음).
- **보안 설정(CSP `style-src 'self'`) 지키기**: HTML `style` 속성을 쓰지 않습니다. 모양은 CSS 파일의 클래스로, 화면 크기에 따라 계산하는 값(배율 `s`로 구한 글씨 크기 등)은 JS에서 `element.style.setProperty('--이름', 값)`으로 CSS 변수에 넣고 CSS가 그 변수를 씁니다. 이 지시서의 `screens` 그림과 캔버스는 설명용이라 style 속성으로 그려져 있지만, 앱 코드는 이 규칙을 따릅니다.
- **색은 `--uc-*` 변수만**: 화면 코드에 색 값을 직접 쓰지 않습니다. 기존 색 값은 가장 가까운 변수로 바꿉니다.
- **누르는 것은 모두 44×44px 이상** (`--uc-touch-min`). 전자칠판 터치 기준입니다.
- **어두운 테마 없음**. 관련 코드도 만들지 않습니다.
- **움직임 최소**: 화면 전환·버튼에 애니메이션을 넣지 않습니다. 눌렀을 때 살짝 어두워지는 정도(`filter: brightness(0.96)`)만.
- **AI 티 금지**: 그라데이션, 유리 효과(blur), 네온 그림자, 이모지(🎉 등), 영어 문구(ON/OFF 등), 장식용 아이콘 남발, 없는 통계 숫자를 넣지 않습니다. 교실 게시판처럼 글씨 크기와 여백으로만 정리합니다.
- **연한 회색 글자 금지**: 지금 쓰는 `#AEB3BA` 같은 연한 글자는 `--uc-text-3`(#6B7380) 이상으로 바꿉니다.

## 3. 2단계 — 대시보드 (A01–A18)

### 3-1. 배율

화면 크기가 바뀌면 모든 크기가 함께 커지고 작아집니다.

```
s = min(창 너비 / 1440, 창 높이 / 900)
clamp(x, 최소, 최대) = min(최대, max(최소, x))
```

아래 크기 공식은 모두 1440×900 기준값에 `s`를 곱하고, 정수로 반올림합니다. 창 크기가 바뀔 때마다 다시 계산합니다.

### 3-2. 바깥 틀

| 항목 | 값 |
|---|---|
| 바깥 여백 P | `clamp(28s, 16, 40)` (아래쪽은 P의 절반) |
| 칸 사이 G | `clamp(16s, 10, 22)` |
| A 머리글 높이 | `136s` (B는 0) |
| B 왼쪽 기둥 폭 | `clamp(330s, 250, 420)`, 기둥과 칸 사이 G |
| 출처 줄 높이 | 24px (12px 글씨, 왼쪽 "우리 교실 · 자동으로 채워지는 우리 반의 하루", 오른쪽 날씨·학교 정보·지도 출처) |
| 아래 도구 막대 높이 | `max(64, 76s)` |
| 칸 모서리 | `clamp(16s, 12, 20)` |
| 칸 영역 | 12열 × 6행 격자, 칸 사이 G |

**기본 배치** (열, 행, 가로 칸 수, 세로 칸 수)

| 칸 | A 기본 | B 기본 | 급식 숨김(A·B) |
|---|---|---|---|
| 오늘 시간표 | 1, 1, 3, 6 | 1, 1, 3, 6 | 1, 1, 3, 6 |
| 아침활동 | 4, 1, 6, 4 | 4, 1, 9, 3 | 4, 1, 9, 4 |
| 안내사항 | 4, 5, 6, 2 | 4, 4, 5, 3 | 4, 5, 9, 2 |
| 오늘의 급식 | 10, 1, 3, 6 | 9, 4, 4, 3 | 숨김 |

숨긴 칸의 자리는 다른 칸이 늘어나서 채웁니다(기존 배치 기능 그대로).

### 3-3. A 머리글 (A01)

- **왼쪽**: 작은 줄 "우리 교실 · 함께 여는 하루" `max(12, 14s)` → 학교 이름 "옥구초등학교 6학년 1반" 고운바탕 700 `max(22, 34s)` → 날짜 `max(16, 24s)` + D-Day 표시.
- **가운데**: 날씨 아이콘 `64s` + 기온 고운바탕 `58s` + 날씨 글 `max(16, 22s)` / 최고·최저·강수 `max(13, 16s)` + 미세먼지 표시(`.uc-dust--*`, 높이 `max(28, 34s)`).
- **오른쪽**: 시계 고운바탕 700 `74s`, 아래에 "지금 2교시 수학" `max(16, 23s)` + "10:30까지"(`s ≥ 0.9`일 때만).
- 머리글에 있던 버튼 4개(배치 편집 · 화면 설정 등)는 **아래 도구 막대로 옮깁니다**(3-9).

### 3-4. B 왼쪽 정보 기둥 (A11)

- 흰 바탕 칸(모서리 `20s`, 안쪽 여백 위아래 `26s` · 좌우 `24s`, 줄 사이 `18s`).
- 위에서부터:
  1. 작은 줄 `max(12, 13s)`
  2. 학교 이름 `max(18, 26s)`
  3. 날짜 `max(15, 19s)`
  4. D-Day 표시(세로로 쌓기, 최대 2개, 폭은 기둥 안쪽 폭까지)
  5. 시계 `92s`
  6. **지금 교시 상자**: 바탕 `--uc-now-bg` + 3px `--uc-now-border` 테두리, 모서리 `16s`. "지금" 표시 + "2교시" `max(16, 20s)`, 과목 고운바탕 `58s`, "10:30까지 · 10분 남음" `max(13, 16s)` + 진행 막대(높이 `max(6, 8s)`).
  7. 빈 공간
  8. 날씨(아이콘 `56s`, 기온 `50s`, 날씨 글 `max(15, 19s)`, 미세먼지) + "학교 소재지 · 11.12. 오전 10:20" 작은 글.
- 교시 시간이 없으면 지금 교시 상자 자리에 점선 상자 "교시 시간 미설정 / 교시 시간을 넣으면 지금 교시와 남은 시간이 여기에 크게 나와요. / [교시 시간 설정]" (A16).

### 3-5. 칸 공통

- `.uc-card` + 색 이름(`--blue` 시간표, `--green` 아침활동, `--yellow` 안내사항, `--pink` 급식).
- **칸 머리 높이** = `clamp(min(62s, 칸높이 × 0.28), 44, 74)`. 모든 칸이 이 공식 하나를 써서 제목 크기가 들쭉날쭉하지 않게 합니다.
- 칸 제목: 고운바탕 700, 크기 = `clamp(min(머리높이 × 0.46, 남은폭 ÷ 제목글자폭), 15, 38)`, 넘치면 말줄임.
- 칸 머리 오른쪽 [수정]/[작성]: 44px 높이 글자 버튼, 반투명 흰 바탕(`rgba(255,255,255,0.75)`), 글자색은 칸 제목색.
- 칸 안쪽 여백 = `clamp(min(칸폭, 칸높이) × 0.055, 10, 26)`.
- 시간표·급식 칸이 충분히 높으면(`≥ 300s`) 맨 아래에 "자동 조회 · 오전 10:20" 13px.

### 3-6. 칸별 내용

**오늘 시간표**

- 몸통의 가로/세로 비가 **2.4 이하면 세로 목록**, 넘으면 **가로 6칸**(A05).
- 세로 목록:
  - 줄 높이 = (몸통 높이 − 줄 사이 × 5) ÷ 6.
  - 과목 글씨 = `clamp(min(줄높이 × 0.5, 몸통폭 × 0.17), 13, 76)`.
  - 줄마다 [번호 네모] + 과목(고운바탕 700) + 시작 시각(작은 고딕).
  - **과목 이름은 줄어들지 않게** 하고(`flex: none`), 공간이 모자라면 시각이 먼저 줄거나 숨습니다.
- **지금 교시**:
  - 줄 바탕 `--uc-now-bg` + 3px `--uc-now-border` 테두리 + 오른쪽 "지금" 표시(`.uc-tag-now`).
  - 지난 교시는 글자를 `--uc-text-3`로 낮춥니다.
  - "다음" 표시는 없습니다.
- 가로 6칸: 칸마다 "1교시 · 09:00" 작은 글 + 과목 큰 글. 지금 교시 칸만 강조 바탕 + 테두리.
- 교시 시간이 없으면 강조 없이 번호와 과목만 보여 줍니다.
  - A 구조에서는 칸 맨 아래에 "교시 시간을 넣으면 지금 교시가 강조돼요 [교시 시간 설정]" 줄을 둡니다.
  - B 구조는 기둥에 같은 버튼이 있으므로 칸에는 넣지 않습니다.

**오늘의 급식**

- 몸통 비율이 2.4 초과면 3단, 1.15 초과면 2단, 아니면 1단으로 메뉴 6개를 나눕니다.
- 메뉴 이름은 고운바탕 700. 알레르기 번호는 이름 옆(좁으면 아래)에 이름 글씨의 0.46배, `--uc-text-3`.
- 원본의 "(5.6.13.16.)"은 화면에서 "5·6·13·16"으로 바꿔 보여 줍니다. 저장된 원본 문자열은 그대로 둡니다.

**아침활동 · 안내사항**

- 글씨는 칸 크기에 맞춰 자동으로 줄어드는 방식(기존 기능)을 유지하되, **최대 크기를 `clamp(40s, 22, 52)`로 낮춥니다.** 칸이 커져도 글씨가 그 이상 커지지 않습니다(사용자 요청: 아침활동 글씨가 너무 큼).
- 고운바탕 700, 줄 간격 1.4, 단어 단위 줄바꿈(`word-break: keep-all`).
- **빈 상태**(A06):
  - 점선 상자(`.uc-empty`) 안에 칸 아이콘 + "오늘 아침활동이 아직 없어요" / "한 번 저장하면 매일 자동으로 표시됩니다" + [+ 아침활동 작성] 버튼.
  - 안내사항은 "오늘 안내사항이 없어요" / "작성하면 학생 화면에 크게 표시됩니다" + [+ 안내사항 작성].
  - 칸이 낮으면 아이콘과 둘째 줄을 빼되, **버튼은 44px를 유지**하고 글씨는 15px 이상.
  - 빈 상태일 때는 머리의 [수정] 버튼을 숨깁니다(같은 동작 중복 방지).

### 3-7. D-Day 표시 (연보라)

### 3-8. 배치 편집 모드 (A07, A17)

  - 왼쪽: "화이트보드" + 도구 고르기([펜][지우개][글자 · 선택]) + 색 점 + [가−] 36px [가+] + [사진 추가] + [ⓘ].

### H 알림장 (H01–H03)

### 4-1. 알림장 칠판 모드 (H05–H10) — 새 기능

기능 · 저장 · 테스트의 자세한 내용은 사용자가 따로 준 **「작업 지시서 — 알림장 칠판 모드」**를 따릅니다. 여기에는 **모양**만 정리합니다. H 알림장을 마친 뒤 이어서 진행합니다.

**알림장 화면의 [칠판 모드] 버튼** (H01–H03, H05)

- 위치: **오른쪽 열 맨 위**에 새 묶음 **"교실에 띄우기"**(고운바탕 24px 제목)를 두고, 그 아래에 버튼을 놓습니다. 그 밑에 얇은 선(1px, `--uc-line-soft`)을 긋고 기존 "보내기" 묶음이 이어집니다. 머리(작성 날짜 옆)에는 버튼을 두지 않습니다. 눈에 잘 띄어야 하기 때문입니다.
- 모양: 열 폭을 꽉 채우는 큰 버튼. 높이 64, 모서리 14, 고운바탕 24px 700, `icons/chalkboard.svg` 26px + "칠판 모드".
  - 색은 칠판을 미리 보여 주는 뜻으로 바탕 `--uc-chalk-bg`, 글자 `--uc-chalk-text`, 테두리 3px `--uc-chalk-frame`.
  - 아래 [등록] 버튼(남색)과 색이 달라서 헷갈리지 않습니다.
- 버튼 아래 14px `--uc-text-3` 안내 "쓴 알림장을 초록 칠판에 크게 띄웁니다".
- 본문이 비면 흐린 버튼(disabled: 바탕 `--uc-surface-2`, 글자 `--uc-text-disabled`)이 되고, 안내 글이 `--uc-warning` 색 "알림장 내용을 먼저 적어 주세요"로 바뀝니다 (H05).

**칠판 화면** (H06–H10)

- 앱 창 전체를 덮습니다. 바깥에 나무 테두리 `--uc-chalk-frame`을 `clamp(12s, 10, 14)`px, 안쪽은 단색 `--uc-chalk-bg`.
- 안쪽 여백: 좌우 `clamp(64s, 36, 96)`, 위 `clamp(48s, 28, 72)`, 아래는 도구 막대 높이 + 28px(막대가 떠 있어도 마지막 줄을 가리지 않게).
- 위에서부터 왼쪽 정렬로 채웁니다(가운데 정렬 아님).
  1. 날짜 "11월 13일 금요일": 본문의 0.7배, `--uc-chalk-accent`, 아래 간격 본문 × 0.25.
  2. 제목: 본문의 1.15배, `--uc-chalk-accent`, 아래 간격 본문 × 0.35. 비어 있으면 줄 생략.
  3. 본문: `--uc-chalk-text`, 쓴 그대로 한 줄씩(`white-space: pre-wrap`), 빈 줄은 한 줄 높이 간격.
- 글씨: 고운바탕 700, 줄 간격 1.5, `word-break: keep-all`.
- 자동 맞춤: 본문 28px ~ `min(12vh, 120px)` 사이에서 한 화면에 다 들어가는 가장 큰 크기. 최소 크기로도 넘치면 줄 단위로 쪽을 나눕니다. **새 쪽이 빈 줄로 시작하면 그 빈 줄은 빼고**, 날짜·제목은 쪽마다 다시 보여 줍니다(H09·H10).
- **도구 막대**:
  - 위치: 화면 아래 가운데, 칠판 위에 뜬 막대. 바탕 `--uc-chalk-bar`(흐림 효과 없음), 모서리 18, 안쪽 여백 10, 버튼 사이 8.
  - 버튼: 높이 56, 최소 폭 56, 나눔바른고딕 18px 700, 모서리 12, 테두리 `--uc-chalk-btn-line`, 바탕 `--uc-chalk-btn-bg`, 글자 `--uc-chalk-text`.
  - [닫기]만 밝은 바탕(`--uc-chalk-text` 바탕 + 칠판색 글자)으로 눈에 띄게 합니다.
  - 순서: `[가−][가+][맞춤] | [날짜 숨기기] | [이전] 1 / 2 [다음] | [전체 화면][닫기]` (세로선은 1px, 높이 32, 분필색 22% 투명도).
  - 쪽이 하나면 [이전]·쪽 표시·[다음]과 그 앞 세로선을 숨깁니다. 첫 쪽의 [이전], 마지막 쪽의 [다음]은 흐리게 합니다.
  - 3초 동안 움직임이 없으면 막대를 숨깁니다(H07).
- 분필 가루, 칠판 질감 그림, 그라데이션, 반짝임, 이모지, 손글씨 글꼴은 쓰지 않습니다.

## 8. 7단계 — 마지막 확인 목록

두 브랜치 각각에서 아래를 확인하고 결과를 사용자에게 알려 주세요.

- [ ] 1440×900, 1100×760, 1920×1080에서 대시보드 A·B 모두 칸이 잘리거나 겹치지 않는다.
- [ ] 화면 설정에서 A ↔ B를 바꿔도 각자의 칸 배치가 따로 기억된다. 앱을 껐다 켜도 유지된다.
- [ ] 대시보드 · PIP 어디에도 '다음 교시'가 없다. 설정의 PIP 항목은 4개다.
- [ ] 시간표 과목 이름이 좁은 칸에서도 사라지지 않는다(시각이 먼저 숨는다).
- [ ] D-Day 0 · 1 · 2개, 긴 제목, 당일 "D-Day"가 화면과 같다.
- [ ] 빈 아침활동 · 빈 안내사항 · 교시 시간 미설정 화면이 A06/A16과 같다.
- [ ] 배치 편집에서 크기 표시가 글자를 덮지 않는다. 숨긴 칸 다시 넣기 · 기본 배치로 · 취소 · 완료가 모두 동작한다.
- [ ] 화면 잠금에서 수정 버튼이 모두 사라지고 도구가 5개만 남는다.
- [ ] 모든 대화 상자가 같은 틀이다(제목 · [×] 위치 · [취소][저장] 순서).
- [ ] 타이머 버튼 순서가 상태에 따라 바뀌지 않는다(창 · PIP 모두).
- [ ] PIP 활동완료에서 이름을 눌러 완료를 바꿀 수 있고, PIP 랜덤 뽑기에서 중복 없이 켜기·끄기가 된다.
- [ ] 누르는 것이 모두 44px 이상이다(개발자 도구로 몇 군데 재기).
- [ ] 글꼴이 고운바탕 · 나눔바른고딕 두 가지뿐이다(시스템 글꼴로 떨어지는 곳 없음, 타이머 숫자 포함).
- [ ] 이모지 · 그라데이션 · 흐림 효과 · 영어 문구(ON/OFF 등)가 없다.
- [ ] 저장된 기존 데이터(명단, 시간표, 알림장 초안, 배치, D-Day)가 그대로 보인다.
- [ ] 판별 화면이 맞다: 옥구초판은 H01·I01, 전국판은 H02·H03·I02·I06.
- [ ] 알림장 칠판 모드가 H05–H10과 같다(빈 본문이면 버튼 흐림, 자동 맞춤, 쪽 나누기, 막대 3초 뒤 숨김, 본문 명암비 7:1 이상).
- [ ] HTML `style` 속성이 새로 생기지 않았다(CSP `style-src 'self'`).
