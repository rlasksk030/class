# v1.8.11 재배포 준비

2026-11-05 사용자가 전국용과 옥구초 전용을 다시 배포하도록 요청했다. 현재 두 판의 최신 공개본은 1.8.10이다. 설치된 앱에서도 새 업데이트로 인식하도록 버전 번호를 1.8.11로 올린다. 기능 코드는 변경하지 않고 app/package.json의 version만 변경한다.

기존 1.8.10 설치 파일·Release·소스·감사 로그는 그대로 보존한다. 전국용 generic feed와 옥구초 GitHub Release 공급자는 분리된 상태로 유지한다.

예상 CI: 공개 저장소의 무료 표준 windows-2022 14개(판별 전체 회귀/빌드 2, 공통 설치 A–I 9, 1.8.10→1.8.11 업그레이드 2, 채널 검사 1), ubuntu-latest 게시 1개를 단일 workflow로 실행한다. 같은 판을 중복 빌드하지 않고 Actions cache/artifact는 사용하지 않는다. 실행 전 확인한 전체 Actions 실행 수는 18회이며 마지막 배포 실행 41974820432는 SUCCESS이다. 예산·차단·결제 설정은 변경하지 않는다.

신규 Windows 검증은 아직 미실행이다. 모든 필수 게이트 통과 전 공개 매니페스트를 갱신하지 않는다. 최종 상태와 해시는 후속 배포 기록에 남긴다.
