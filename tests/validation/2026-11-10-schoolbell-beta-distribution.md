# 우리 교실 전국용 — 학교종이 베타 테스트판 배포 계획

> 상태: **베타 설치 파일 미생성 / 미배포**. 이 문서는 설치 가능한 파일이나 배포 완료 증거가 아니다.
> 정식 전국용 v1.8.11, 옥구초 전용 앱, 자동 업데이트 채널은 변경하지 않는다.
> 작업 기준: 실제 학교종이 앱 자동 게시 1회 완주 PASS(2026-11-10), 운영 일반 학급/Windows 최종 검증은 미완료.

## 목적과 배포 원칙

교사 검증을 위해 전체 정식 출시 게이트보다 먼저 **명시적 참여자를 위한 별도 Windows x64 베타판**을 준비한다. 베타의 설치·실행·개인정보 보호·롤백을 최소 검증하고 제한 배포한다. 베타는 정식 자동 업데이트가 아니다.

- 개발 코드: `feature/schoolbell-diary-nationwide`, PR #5 Draft 유지. 사용자 요청 없는 main 병합, 정식 태그, 정식 전국용 Release, nationwide.yml 업로드 금지.
- **베타와 운영판 격리**: 별도 appId/productName/설치 폴더/userData, 예: `classroom-dashboard-beta`; 운영판 `%APPDATA%/classroom-dashboard`와 절대 공유·이동·마이그레이션하지 않는다. 베타에서 운영판 자동 업데이트 감지/적용 금지.
- 별도 설치 파일명 및 명시적 `BETA / 테스트용` 식별, GitHub의 일반 Release가 아닌 **pre-release** 혹은 제한된 검증용 배포 경로. 브랜치 소스 zip이나 기존 v1.8.11 EXE를 새 기능 테스트판이라고 명명하지 않는다.
- **학생·학부모가 있는 실제 학급에 게시 금지**. 로그인·학급/수신자 UI 관찰은 비게시로 제한하고, 베타 자동 게시 시험은 본인 소유의 **수신대상 0명 테스트 학급** + 필수 관리자 본인 알림 확인 + 시험 문구/사진 + 최종 사용자 확인 + 건별 1회 전송 조건만 허용한다. 실서비스 자동화 허용 범위를 확인했다고 주장하지 않는다.
- 시험판에서 고유 계정 권한을 검증하지 못한 일반 운영 학급은 게시 기능 잠금 유지. 사용자에게 시험 데이터 외 개인정보 업로드/보내기를 요구하지 않는다.
- 화면/본문/학생/연락처/인증값·쿠키·사진 원본을 GitHub 진단 로그로 업로드하지 않는다. 익명화된 운영체제/앱버전/단계/오류코드/사진 건수만 수집한다.

## 우선 수행 작업

1. 베타 빌드가 정식판과 별도 userData, 별도 설치 경로, 별도 update feed라는 것을 코드·설치 스모크로 확인한다. 정식판 자료 손상 가능성이 있으면 파일을 배포하지 않는다.
2. 기존 `app/schoolbell-capability.cjs`의 정식 운영 잠금은 유지한다. 패키징된 베타라도 테스트 전용 제한 게시 계약이 기존 개발 시험의 안전조건을 전부 유지해야 하며, 단순 `enabled=true`는 금지한다.
3. Windows x64 설치 파일을 로컬 환경에서 빌드하고 **적어도 설치·실행·종료·재실행·베타/정식 프로필 격리·기본 알림장 UI·검사 환경**을 확인한다. 최소 스모크 실패 시 배포 보류; 나머지 전체 릴리스 검증과 별도 기록한다.
4. EXE의 SHA-256, 정확한 소스 커밋 SHA, 버전, 빌드 방법, 알려진 제한, 되돌리기/제거 방법을 포함한다. 파일 크기·SHA가 실제 검증되기 전에는 다운로드 링크가 있다고 주장하지 않는다.
5. **베타 테스트를 실제로 수행한 교사**로부터 설치 성공/실패, Windows 버전, 기존 정식판과의 공존, 학교종이 로그인, 학급 정보 화면, 사진 첨부(테스트 학급), 비게시 조회, 오류 코드를 수집한다. 운영 학급 게시 시험을 시키지 않는다.
6. 교사 사용성 피드백으로 발견된 문제를 수정하고 운영 학급 권한/수신자 가드 및 Windows 기존 v1.8.11 업그레이드 시나리오 A–I의 필수 정식 출시 검증을 끝낸 뒤 **정식 Release**로 승격한다. 베타 PASS를 정식 출시 PASS로 대체하지 않는다.

## 테스터에게 보일 안내

**우리 교실 전국용 학교종이 연동 베타판 — 테스트 용도.**
기존 정식판과 별도로 설치되며, 학생·학부모 실데이터를 입력하거나 실제 운영 학급으로 알림장을 게시하지 마세요.
테스트 학급에서 로그인/알림장 작성/사진 첨부/게시 전 검증/게시 결과 조회를 확인하고, 오류 발생 시 원문·개인정보가 포함되지 않은 단계별 결과만 제보해 주세요.
신규 시험 게시에는 수신자 0명, 관리자 본인 확인, 건별 전송 승인이 필요합니다.
