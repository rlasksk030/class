- 타이머 대화상자에 PIP 진입 버튼, 전용 남은 시간 표시, 시작·일시정지·계속하기·재시작·초기화·종료 확인을 추가했다.

- 버전 번호·업데이트 채널·설치 경로·워크플로는 변경하지 않았다. 기존 설치 파일과 배포 기록은 유지했다.

## 비용 및 CI

- 작업 전 확인: 유일한 워크플로는 기존 Windows 검증 브랜치 push와 수동 dispatch로 실행된다. PR 이벤트 실행은 없다.
- 신규 `feature/timer-pip-nationwide`, `feature/timer-pip-okgu` 브랜치는 push 트리거에 해당하지 않는다. 커밋 메시지에 `[skip ci]`도 사용한다.
- 예상 Actions 실행 0회, 수동 실행 요청 0회. 시작 시 전체 이력 15회, 마지막 실행 ID `37741006999` (2026-10-08).
- 11월 무료 잔여량·예산 상태를 읽는 계정 관리 기능은 현재 연결에 없으므로 잔여 무료 분량을 확인했다고 주장하지 않는다. Actions를 실행하거나 예산·결제·권한을 변경하지 않는다.
- 기존 워크플로, 검증 게이트, 감사 원본을 삭제하거나 축소하지 않았다.
