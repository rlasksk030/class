# 옥구초용·전국용 업데이트 분리 검증

앱 소스는 `f78cb9938955212b23ac1bb7b17c45a3a80ca01f`다. 옥구초용은 공식 v1.8.7 설치파일, 전국용은 처음 배포했던 v1.8.8과 새 v1.8.9 설치파일로 검사했다.

| 설치된 판 | Windows에서 확인한 업데이트 원본 | 전환 |
|---|---|---|
| 옥구초 전용 v1.8.7 | `rlasksk030/class`의 정식 GitHub Release와 그 버전의 `latest.yml` | 기존 앱을 계속 사용 |
| 전국용 v1.8.8 | 옥구초용과 같은 기존 GitHub Release | 전국용 v1.8.9를 기존 폴더에 한 번 설치 |
| 전국용 v1.8.9 | `downloads/nationwide` 브랜치의 `nationwide.yml`과 그 위치의 전국용 x64 EXE | 이후 프로그램 안에서 전국용 업데이트 확인 |

## 실행 결과

- Windows 11 ARM64 격리 VM에서 실제 x64 설치본 두 개의 업데이트 모듈을 실행했다. 서비스 응답에만 가상 버전을 제공했고, 설치본이 설정한 공급자와 주소를 유지했다. 한쪽에만 새 버전이 있으면 다른 판은 최신으로 표시했다. 두 판 모두 사용자가 확인한 뒤 각 판의 설치파일 URL만 요청했다. 가상 미래 버전의 설치 실행은 다운로드 요청 단계에서 중단했다.
- 전국용 목록에 옥구초용 EXE를 넣거나 목록을 읽지 못하게 해도 설치가 차단됐고 다른 채널로 연결되지 않았다. 재현 코드는 `tests/windows/update-channels.cjs`에 있다.
- 기존 전국용 v1.8.8에서 같은 폴더에 v1.8.9를 설치하고 재실행했다. 학년·반, 합성 학생 명단, 알림장 초안의 원래 값을 확인했다. 업데이트 설정은 전국용 주소로 바뀌었고 화면에는 ‘전국용 · 현재 버전 1.8.9’가 표시됐다.
- v1.8.9 EXE는 99,316,477바이트이며 SHA-256은 `86ceba98741d77e9eb45a660c4d252ae42cc21f9ab463f2bea26d71b52c39ff1`이다. 설치파일의 SHA-512와 매니페스트, 패키지의 앱 파일 78개와 소스, 런타임·빌드 설정의 업데이트 주소를 대조했다.
- 로컬 단위 검사 50/50. 기존 학교 전환 검사에서 첫 자동 조회와 합성 서비스 준비 순서가 겹쳐 시간 초과가 한 차례 발생했다. 합성 서비스가 준비된 페이지에서 검사를 시작하도록 고친 뒤 해당 5개 검사가 통과했고, 이어서 실행한 전체 Electron 회귀 검사도 17개 묶음 304/304가 통과했다.

전국용 배포 커밋은 `cf0604e68f6afbf5160b9168f3861b7bb56466ac`다. GitHub의 전국용 고정 브랜치 주소에서 인증 없이 내려받은 EXE·블록맵·매니페스트가 빌드 원본과 바이트 단위로 일치했다. 옥구초용 정식 Release의 `latest.yml`은 여전히 v1.8.7이고 SHA-256은 `1f7cb8b6d7419f47ff188249dfc7d8b42f47427a7b312d762b7aa0626e2a4bfd`다.

배포 절차와 사용자 전환 방법은 [전국학교 시작 안내](../../전국학교_시작안내.md)에 있다.
