# 학교종이 자동 등록 후속 계획

기준: feature/schoolbell-diary-nationwide, f9ea20170a3249b3695b934d60ce6a171af3f760. 사용자가 지목한 1663a948bbb4 이후 변경은 기존 실행 증거 보존 커밋이다. PR #5 / Issue #4를 계속 사용한다.

1. 공식 웹 매뉴얼·약관·게시판 연동 안내와 로그인 전 공개 화면을 다시 조사한다. 게시 API 미확인을 기술적 불가능으로 단정하지 않고 Electron 교사 세션의 웹 UI 방식도 검토한다.
2. 관찰된 공식 로그인 이동을 지원하되 임의 URL·인증 매개변수·외부 이동은 차단한다. 사용자 확인과 서버/교사 권한 검증을 구분한다.
3. 공식 허용 증거와 승인 테스트 계정이 없으므로 실제 사이트용 입력/게시 드라이버는 활성화하지 않는다. 이 조건은 사용자 답변으로 확인했다. 미관찰 DOM 선택자와 내부 API를 추측하지 않는다.
4. 구현 가능한 자동 등록 처리기를 분리한다: 대상/권한 확인, 취소 가능한 게시 전 확인, pending 선저장, 제목·본문·원본 사진 순서 대조, 한 번만 게시, 새 게시물 읽기 결과 대조, 불확실한 결과 재시도 금지. 수동 이력과 자동 시도 기록을 분리하고 기존 초안/사진을 변경하지 않는다.
5. 합성 드라이버와 화면으로 실패·중복·재시작·사진 원본·결과 확인을 검사한다. 합성 PASS를 실제 학교종이 자동 등록 PASS로 표시하지 않는다. 기존 하이클래스 및 채널 분리 검사도 수행한다.
6. 구현 후 별도 검토 단계에서 실제 코드와 부정 사례를 대조한다. Windows 변경 코드 검사는 별도로 기록한다. 실행하지 않은 항목은 NOT RUN, 정책/계정 차단은 BLOCKED로 표기한다.
7. 감사 기록을 추가하고 작업 브랜치만 commit/push, Issue #4에 결과 기록, 기존 Draft PR #5 갱신. main/배포/운영 채널/Actions는 변경하지 않는다.

정식 배포 판정은 허용·실계정·패키지 검증·최종 승인 전까지 NO GO이다.
