# v1.8.10 타이머 PIP 배포 준비

2026-11-05 사용자가 전국용과 옥구초 전용 배포를 승인했다. 각 판의 업데이트 공급자, 앱 ID, 사용자 데이터 폴더와 NSIS 업그레이드 보호 장치를 그대로 유지한다.

- 전국용: downloads/nationwide의 nationwide.yml, classroom-dashboard-nationwide-setup-1.8.10-x64.exe.
- 옥구초 전용: 정식 GitHub Release v1.8.10의 latest.yml, classroom-dashboard-setup-1.8.10.exe.
- 로컬 문법·단위 검사 결과는 2026-11-05-timer-pip.md에 있다. Windows 실행 검사는 아직 미실행이며 통과로 기록하지 않는다.
- Linux 로컬 패키징은 Wine의 Unix 소켓 생성이 환경에서 거부되어 중단됐다. 이 환경 제한을 우회하지 않는다. 부분 생성된 설치 파일은 배포하지 않는다.
- 공개 저장소의 무료 표준 Windows 실행기에서 한 차례 배포 검증을 진행한다. 유료 실행기·캐시·Actions artifact 저장소를 사용하지 않고 예산 및 차단 설정을 변경하지 않는다.
- 두 판의 전체 Electron 회귀 검사, 설치 파일 무결성, 기존 Windows 설치 시나리오 및 업데이트 채널 검사 결과가 확인되기 전에는 공개 업데이트 목록을 갱신하지 않는다.
- 성공·실패 및 실행 링크를 후속 감사 기록에 남긴다. 기존 커밋, 릴리스와 감사 원본은 보존한다.
