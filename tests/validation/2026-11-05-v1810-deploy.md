# v1.8.10 타이머 PIP 배포 준비

2026-11-05 사용자가 전국용과 옥구초 전용 배포를 승인했다. 각 판의 업데이트 공급자, 앱 ID, 사용자 데이터 폴더와 NSIS 업그레이드 보호 장치를 그대로 유지한다.

- 전국용: downloads/nationwide의 nationwide.yml, classroom-dashboard-nationwide-setup-1.8.10-x64.exe.
- 옥구초 전용: 정식 GitHub Release v1.8.10의 latest.yml, classroom-dashboard-setup-1.8.10.exe.
- 로컬 문법·단위 검사 결과는 2026-11-05-timer-pip.md에 있다. Windows 실행 검사는 아직 미실행이며 통과로 기록하지 않는다.
- Linux 로컬 패키징은 Wine의 Unix 소켓 생성이 환경에서 거부되어 중단됐다. 이 환경 제한을 우회하지 않는다. 부분 생성된 설치 파일은 배포하지 않는다.
- 공개 저장소의 무료 표준 Windows 실행기에서 한 차례 배포 검증을 진행한다. 유료 실행기·캐시·Actions artifact 저장소를 사용하지 않고 예산 및 차단 설정을 변경하지 않는다.
- 두 판의 전체 Electron 회귀 검사, 설치 파일 무결성, 기존 Windows 설치 시나리오 및 업데이트 채널 검사 결과가 확인되기 전에는 공개 업데이트 목록을 갱신하지 않는다.
- 성공·실패 및 실행 링크를 후속 감사 기록에 남긴다. 기존 커밋, 릴리스와 감사 원본은 보존한다.

## 최초 Windows 실행 결과

실행: https://github.com/rlasksk030/class/actions/runs/41973411843

- 전국용 문법·단위 검사 통과. Electron 회귀 검사 중 새 PIP 시나리오의 60초 설정에서 실패했다. 테스트 helper가 max=59인 초 입력칸에 60을 넣어 브라우저 검증이 적용을 막았다. 1분 0초로 입력하도록 분/초 분해를 수정했다.
- 옥구초용 문법·단위 검사 통과. 기존 regression의 1200ms 고정 대기 후 표시 검사가 실패했다. 판정용 첫 읽기와 로그용 두 번째 읽기 사이에 정상 00:02로 갱신된 것을 확인했다. 실제 남은 시간의 갱신을 기다리고 한 번 읽은 값과 실행 중 상태·닫힌 팝업을 함께 검사하도록 수정했다.
- 앱 기능 코드 변경은 없다. 실패한 검사 원인을 수정한 후 새 실행에서 전체 회귀 검사를 진행한다. 타이머 검사를 먼저 배치하며 같은 실행에서 중복하지 않는다.
- 첫 실행은 두 빌드의 검사 단계에서 중단됐다. 설치 파일 빌드, 설치 시나리오, 공개 업데이트는 실행되지 않았다. 환경 차단과 테스트 실패를 구분한다.

## 이어서 실행하는 범위

전국용 전체 회귀 및 Windows 패키징은 다시 하지 않는다. Ubuntu에서 이전 성공 작업 상태와 고정 소스 SHA, 저장된 산출물 SHA-256·SHA-512를 대조하여 동일 빌드를 재사용한다. 옥구초용은 수정된 사진 검사부터 전체 기존 Electron 16개 스크립트를 한 번씩 실행하고 처음으로 패키징한다.

공통 NSIS 템플릿은 두 판에서 동일하므로 기존 A–I는 옥구초 후보로 한 번씩 실행한다. 두 판 최신 배포본에서 같은 폴더 업그레이드 및 데이터 보존, 설치본 PIP, 기존/신규 옥구초와 전국용 업데이트 채널 검사는 각각 유지한다. 최종 공개는 전부 통과한 뒤에만 한다. 이번 실행 계획: Windows 13개, Ubuntu 검증 재사용 1개와 게시 1개. Actions cache/artifact 0개, 예산·차단·유료 설정 변경 없음.
