# Bundled font sources

- Gowun Batang Regular/Bold: https://github.com/google/fonts/tree/main/ofl/gowunbatang (GowunBatang-OFL.txt)
- Nanum Barun Gothic Regular/Bold: NAVER official https://hangeul.pstatic.net/hangeul_static/css/nanum-barun-gothic.css (NanumBarunGothic-LICENSE.txt; NAVER license information: https://help.naver.com/service/11029/contents/18088)

These files are bundled locally for offline use. No runtime font network requests are made.
